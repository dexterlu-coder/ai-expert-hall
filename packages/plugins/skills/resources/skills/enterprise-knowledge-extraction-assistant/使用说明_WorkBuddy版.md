# 企业知识库萃取助手｜WorkBuddy 使用说明

## 一、这个技能做什么

把企业已有的制度、SOP、产品政策、法规合规、培训稿、会议纪要、周报、营销方案、案例、客服话术、项目资料等**原始素材**，判断类型 → 拆分文件 → 萃取成适合智能体、AI 应用、企业私有知识库挂载的结构化 Markdown 文档。

不做什么：不凭空补写企业规则，不处理未授权/未脱敏的敏感资料，不替代业务负责人审核。

## 二、安装位置

- 技能目录：`C:\Users\qiaob\.workbuddy\skills\enterprise-knowledge-extraction-assistant\`
- 主文件：`SKILL.md`
- 配套规则：`references\01~04`
- 千问办公版安装说明：`学员安装与使用说明_千问办公版.md`（如需分发给学员）

## 三、怎样调用

直接说需求即可，技能会自动匹配触发，例如：

> 用企业知识库萃取助手，读取这几份制度文件，判断适合整理成哪些知识库文件并生成。

> 把这批会议纪要和周报萃取成知识库，给智能体回答内部问题用。

> 用企业知识库萃取助手，把这份产品政策拆成多个 Markdown 文件，适配 Dify 知识库。

也可以显式加载：在对话中点「技能」→ 选择「企业知识库萃取助手」。

## 四、使用前准备

- 优先提供近期真实、且以后会重复使用的资料；
- 上传前脱敏：个人信息、客户信息、账号密钥、未公开经营数据；
- 说明知识库最终给谁用、解决什么问题、挂载到哪个平台（Dify / 扣子 / FastGPT / 飞书 / 私有库 / AI 编程项目）；
- 输出结果作草稿用，涉及制度、安全、财务、合同、合规、正式发布的内容由负责人确认。

## 五、典型产出

按素材类型，默认输出 5~7 个编号 Markdown 文件，例如制度类：

```
01_制度适用范围说明.md
02_制度核心规则知识库.md
03_操作流程与审批规则.md
04_常见问题FAQ.md
05_禁止事项与风险边界.md
06_制度执行检查清单.md
```
