# 分行业口径统一默认规则

> 当用户未明确指定收入确认、成本归集、费用分摊规则时，按行业默认规则执行。用户可随时覆盖。

## 1. 制造业

### 收入确认时点

| 业务场景 | 确认时点 | 依据 |
|---------|---------|------|
| 标准产品销售 | 客户签收/验收单日期 | 控制权转移 |
| 出口销售 | 报关单日期（FOB/CIF按贸易条款） | 装船即转移 |
| 工程类项目 | 完工百分比法（按实际成本/总预算成本） | 时段履约 |
| 寄售/VMI | 客户实际领用日期 | 领用即转移 |

### 成本归集规则

| 成本类型 | 归集方法 | 分配基准 |
|---------|---------|---------|
| 直接材料 | 按BOM定额归集到产品/工单 | 实际领料单 |
| 直接人工 | 按工时分摊到产品/工单 | 标准工时×实际工资率 |
| 制造费用 | 按机器工时/人工工时/产量分摊 | 默认: 机器工时 |
| 外协加工 | 按工单直接归集 | 委外订单 |

### 费用分摊方法

| 费用类型 | 分摊基准 | 说明 |
|---------|---------|------|
| 销售费用 | 按产品线收入比例 | 品牌广告费按收入，渠道费直接归集 |
| 研发费用 | 按项目工时/项目预算 | 资本化条件: 技术可行性证明+有市场 |
| 管理费用 | 按部门人数/收入/面积 | 默认按部门人数 |
| 仓储物流费 | 按出库体积/重量/金额 | 默认按出库金额 |

## 2. 零售业

### 收入确认时点

| 业务场景 | 确认时点 | 依据 |
|---------|---------|------|
| 线下门店 | POS收银日（扣除预计退货） | 交付即转移 |
| 电商平台 | 消费者确认收货日/自动收货日（7天） | 平台规则 |
| 预售/定金 | 尾款支付并发货后 | 发货即履约 |
| 礼品卡/储值卡 | 实际消费时（未消费挂递延收益） | 消费时履约 |

### 成本归集规则

| 成本类型 | 归集方法 | 分配基准 |
|---------|---------|---------|
| 商品采购成本 | 按SKU直接归集（移动加权平均/先进先出） | 默认移动加权平均 |
| 门店租金 | 按门店直接归集 | 合同约定 |
| 仓储成本 | 按商品体积/库存天数分摊 | 默认按库存金额 |
| 物流配送 | 按订单直接归集 | 快递单 |

### 费用分摊方法

| 费用类型 | 分摊基准 | 说明 |
|---------|---------|------|
| 平台佣金/服务费 | 按渠道/平台直接归集 | 按平台结算单 |
| 营销推广费 | 按活动/渠道直接归集 | 品牌类按收入分摊 |
| 门店运营费 | 按门店直接归集 | 水电/耗材/保洁 |
| 总部管理费 | 按门店收入比例 | 默认按收入 |

## 3. 服务业

### 收入确认时点

| 业务场景 | 确认时点 | 依据 |
|---------|---------|------|
| 项目制服务 | 里程碑验收/完工百分比 | 按时段或时点履约 |
| 人力外包/驻场 | 按月结算（实际人天×单价） | 按月履约 |
| 一次性服务 | 服务完成+客户确认日 | 交付即转移 |
| 长期合同 | 完工百分比（实际工时/预算总工时） | 时段履约 |

### 成本归集规则

| 成本类型 | 归集方法 | 分配基准 |
|---------|---------|---------|
| 人力成本 | 按项目工时直接归集 | 实际工时×标准工资率 |
| 差旅费 | 按项目直接归集 | 报销单 |
| 外包/分包成本 | 按项目直接归集 | 分包合同 |
| 公共资源 | 按项目工时比例分摊 | 会议室/软件许可等 |

### 费用分摊方法

| 费用类型 | 分摊基准 | 说明 |
|---------|---------|------|
| 销售费用 | 按项目收入/客户收入比例 | 售前投入按客户分摊 |
| 研发/方法论 | 按项目收入比例 | 知识沉淀成本 |
| 管理费用 | 按项目工时/人数比例 | 默认按工时 |
| 招聘培训费 | 按部门人数 | HR成本 |

## 4. SaaS

### 收入确认时点

| 业务场景 | 确认时点 | 依据 |
|---------|---------|------|
| 订阅收入 | 按服务期直线摊销（月/年） | 时段履约 |
| 一次性实施费 | 实施完成+客户确认（或按服务期摊销） | 默认按服务期摊销 |
| 用量计费 | 实际用量结算日 | 消耗即履约 |
| 续费/增购 | 新合同生效日 | 合同约定 |
| 提前续费 | 仍按原到期后的新服务期摊销 | 预收挂合同负债 |

### 成本归集规则

| 成本类型 | 归集方法 | 分配基准 |
|---------|---------|---------|
| 云基础设施 | 按客户/产品直接归集（通过云厂商账单拆分） | 资源标签 |
| 客户成功成本 | 按客户直接归集 | 人力+工具 |
| 实施/交付成本 | 按项目/客户直接归集 | 人天 |
| 研发成本 | 资本化: 平台级功能开发 / 费用化: Bug修复+日常运维 | 技术可行性为标准 |

### 费用分摊方法

| 费用类型 | 分摊基准 | 说明 |
|---------|---------|------|
| 获客成本(CAC) | 按新增客户直接归集 | 含市场+销售薪酬 |
| 销售佣金 | 按签约客户直接归集 | 按合同金额×佣金率 |
| 研发费用 | 按产品线/功能模块分摊 | 按实际人天 |
| G&A | 按ARR/收入比例 | 管理/财务/法务 |

## 5. 金融

### 收入确认时点

| 业务场景 | 确认时点 | 依据 |
|---------|---------|------|
| 利息收入 | 按实际利率法逐日/逐月计提 | 时段履约 |
| 手续费/佣金 | 服务完成日 | 新准则五步法 |
| 投资收益 | 交易日/资产负债表日公允价值变动 | 金融工具准则 |
| 保费收入 | 按保险期间直线摊销 | 时段履约 |

### 成本归集规则

| 成本类型 | 归集方法 | 分配基准 |
|---------|---------|---------|
| 资金成本 | 按业务线/产品实际占用资金计算 | FTP内部资金转移定价 |
| 信用成本 | 按贷款组合计提（预期信用损失模型） | IFRS 9/新金融工具准则 |
| 运营成本 | 按业务线/产品归集 | 活动量驱动 |

### 费用分摊方法

| 费用类型 | 分摊基准 | 说明 |
|---------|---------|------|
| 风险成本 | 按风险资产(RWA)比例 | 资本占用 |
| 合规/风控 | 按业务线收入/资产规模 | 默认按资产规模 |
| 科技投入 | 按业务线使用量/收入 | 按科技预算占比 |
| 管理费 | 按业务线收入/人数 | 默认按收入 |

## 6. 通用默认（未识别行业时）

| 规则 | 默认值 | 说明 |
|------|------|------|
| 收入确认 | 发票/收款日期 | 最保守，提示用户可能虚增当期收入 |
| 成本归集 | 按收入比例 | 假设成本与收入线性相关 |
| 费用分摊 | 按部门人数 | 最常用，无收入数据的部门按人数 |
| 库存计价 | 移动加权平均 | 默认 |
| 折旧 | 直线法 | 默认 |

> 使用通用默认时，必须在输出中标注"⚠️ 未识别行业，使用通用口径规则，建议确认后调整"。
