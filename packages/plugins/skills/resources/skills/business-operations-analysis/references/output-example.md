# 使用示例与输出示意

## 使用示例

### 全量模式（多数据源）

**输入**:
```
请分析本月经营数据：
- 订单系统：order_202607.xlsx
- 财务系统：finance_202607.xlsx
- 分析周期：2026年7月
- 受众：月度经营分析会（管理层）
```

**输出**: Excel + PDF 双格式，5个Sheet完整经营分析。

### 精简模式（单数据源）

**输入**:
```
分析一下7月的经营情况：
- 数据文件：财务数据_202607.xlsx
- 分析周期：2026年7月
```

**输出**: Markdown + Excel 双格式，T1高管看板 + 基础趋势 + 异常清单 + 数据缺口说明。
