# 数据源标准字段规范

> 确保上传的数据文件能被技能自动识别。列名不匹配时会尝试模糊匹配，建议尽量使用标准列名。

## 1. 通用规范

| 规则 | 说明 |
|------|------|
| 文件格式 | `.xlsx` / `.xls` / `.csv`（UTF-8 编码） |
| 日期格式 | `YYYY-MM-DD`（如 `2026-07-01`）或 `YYYYMM`（如 `202607`） |
| 金额单位 | 统一为**元**，不使用万元/亿元（技能自动换算千/万/亿显示） |
| 空值处理 | 留空或填 `N/A`，不要填 `0`（0会被计入均值，扭曲统计） |
| 列名大小写 | 不敏感，中英文均可。但首推标准列名 |
| 第一行 | 必须是表头（列名），不允许标题行/合并单元格 |

## 2. 订单系统

用于计算：收入、客单价、产品线/区域/渠道拆解、转化率、退货率。

### 2.1 必填字段

| 列名（中文） | 列名（英文） | 数据类型 | 示例 | 说明 |
|------------|------------|:---:|------|------|
| 订单编号 | order_id | 文本 | `ORD20260701001` | 唯一标识，不可重复 |
| 订单日期 | order_date | 日期 | `2026-07-01` | 用于按月汇总 |
| 产品名称 | product_name | 文本 | `智能手表Pro` | 用于产品线拆解 |
| 数量 | quantity | 整数 | `2` | 单笔订单该产品数量 |
| 单价 | unit_price | 小数(2位) | `1299.00` | 不含税单价 |
| 实付金额 | paid_amount | 小数(2位) | `2598.00` | 含折扣后实际收款 |

### 2.2 可选字段（有则启用高级分析）

| 列名（中文） | 列名（英文） | 数据类型 | 说明 |
|------------|------------|:---:|------|
| 客户ID | customer_id | 文本 | 用于新老客分析 |
| 区域 | region | 文本 | `华东` / `华南` / `华北` 等 |
| 渠道 | channel | 文本 | `天猫` / `京东` / `线下门店` 等 |
| 品类 | category | 文本 | `手机` / `配件` / `穿戴` 等（比产品名更高一级） |
| 订单状态 | status | 文本 | `已完成` / `已退货` / `待付款` |
| 退款金额 | refund_amount | 小数(2位) | 用于退货率计算 |
| 访客数 | visitors | 整数 | 用于转化率计算（成交数÷访客数） |

### 2.3 CSV 示例

```csv
order_id,order_date,product_name,quantity,unit_price,paid_amount,region,channel,status
ORD20260701001,2026-07-01,智能手表Pro,2,1299.00,2598.00,华东,天猫,已完成
ORD20260701002,2026-07-01,蓝牙耳机,1,299.00,299.00,华南,京东,已完成
ORD20260701003,2026-07-02,智能手表Pro,1,1299.00,1299.00,华北,线下门店,已退货
```

## 3. 财务系统

用于计算：收入确认、成本归集、毛利、费用、净利、经营现金流。

### 3.1 必填字段

| 列名（中文） | 列名（英文） | 数据类型 | 示例 | 说明 |
|------------|------------|:---:|------|------|
| 会计期间 | period | 文本/日期 | `202607` / `2026-07` | 按月汇总 |
| 科目名称 | account_name | 文本 | `主营业务收入` | 财务科目 |
| 科目类型 | account_type | 文本 | `收入` / `成本` / `费用` | 用于自动归类 |
| 金额 | amount | 小数(2位) | `5000000.00` | 借方正数，贷方负数或正数（统一约定：收入成本用正数） |

### 3.2 推荐科目分类

| 科目类型 | 包含科目 | 映射指标 |
|:---:|------|------|
| 收入 | 主营业务收入、其他业务收入、投资收益 | → 营业收入 |
| 成本 | 主营业务成本、原材料、人工成本 | → 营业成本 |
| 费用 | 销售费用、管理费用、研发费用、财务费用 | → 期间费用 |
| 现金流 | 经营性现金流入、经营性现金流出 | → 经营现金流 |

### 3.3 可选字段

| 列名（中文） | 列名（英文） | 数据类型 | 说明 |
|------------|------------|:---:|------|
| 部门 | dept | 文本 | 按部门归集费用 |
| 项目编码 | project_code | 文本 | 按项目核算成本 |
| 预算金额 | budget | 小数(2位) | 用于预算vs实际对比 |
| 去年同期金额 | ly_amount | 小数(2位) | 直接提供同比数据，免查历史 |

### 3.4 CSV 示例

```csv
period,account_name,account_type,amount,dept,ly_amount
202607,主营业务收入,收入,5000000.00,总公司,4800000.00
202607,主营业务成本,成本,3200000.00,总公司,3050000.00
202607,销售费用,费用,800000.00,市场部,750000.00
202607,管理费用,费用,500000.00,行政部,480000.00
202607,研发费用,费用,300000.00,研发部,290000.00
202607,经营性现金流入,现金流,4800000.00,总公司,4600000.00
202607,经营性现金流出,现金流,4100000.00,总公司,3900000.00
```

## 4. 库存系统

用于计算：库存周转天数、库存预警、缺货分析。

### 4.1 必填字段

| 列名（中文） | 列名（英文） | 数据类型 | 示例 | 说明 |
|------------|------------|:---:|------|------|
| 日期 | date | 日期 | `2026-07-01` | 库存快照日期 |
| SKU编码 | sku_code | 文本 | `SKU-WATCH-PRO-BLK` | 唯一商品编码 |
| 产品名称 | product_name | 文本 | `智能手表Pro 黑色` | 与订单系统对应 |
| 期初库存 | opening_stock | 整数 | `1000` | 月初库存数量 |
| 本期入库 | inbound | 整数 | `500` | 当月入库数量 |
| 本期出库 | outbound | 整数 | `800` | 当月出库/销售数量 |
| 期末库存 | closing_stock | 整数 | `700` | 月末库存数量 |

### 4.2 可选字段

| 列名（中文） | 列名（英文） | 数据类型 | 说明 |
|------------|------------|:---:|------|
| 单位成本 | unit_cost | 小数(2位) | 用于计算库存金额和周转天数（金额口径） |
| 安全库存 | safety_stock | 整数 | 低于此值触发补货预警 |
| 仓库 | warehouse | 文本 | 按仓库拆分库存 |
| 库龄天数 | age_days | 整数 | 用于滞销品识别（>90天标记） |

### 4.3 库存周转天数计算

- **数量口径**：平均库存数量 ÷ 日均出库数量
- **金额口径**：平均库存成本 ÷ 日均销售成本（更准确）

### 4.4 CSV 示例

```csv
date,sku_code,product_name,opening_stock,inbound,outbound,closing_stock,unit_cost,safety_stock,warehouse
2026-07-01,SKU-WATCH-PRO-BLK,智能手表Pro 黑色,1000,500,800,700,650.00,200,华东总仓
2026-07-01,SKU-WATCH-PRO-WHT,智能手表Pro 白色,800,300,600,500,650.00,150,华东总仓
2026-07-01,SKU-BUDS-BASIC-BLK,蓝牙耳机 黑色,2000,0,400,1600,120.00,500,华南仓
```

## 5. 单数据源通用模板

如果只有一个Excel文件，建议使用以下列结构（混合型单表），技能会智能识别各列归属：

| 列名（中文） | 列名（英文） | 数据类型 | 归属于 | 示例 |
|------------|------------|:---:|:---:|------|
| 日期 | date | 日期 | 通用 | `2026-07-01` |
| 金额 | amount | 小数(2位) | 通用 | `5000000.00` |
| 类型 | type | 文本 | 通用 | `收入` / `成本` / `费用` |
| 部门 | dept | 文本 | 可选 | `市场部` |
| 产品 | product | 文本 | 可选 | `智能手表Pro` |
| 区域 | region | 文本 | 可选 | `华东` |

技能处理逻辑：
1. 识别 `类型` 或 `科目类型` 列 → 自动归入收入/成本/费用
2. 识别 `日期` 或 `会计期间` 列 → 确定分析周期
3. 识别 `金额` 列 → 计算各项指标
4. 缺失列 → 对应维度标注"数据不足"，不影响其他维度输出
