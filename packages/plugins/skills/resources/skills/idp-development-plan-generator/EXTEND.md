# IDP 个人发展计划生成器 - EXTEND.md

## §A 适用场景

- 绩效面谈后，主管为下属制定发展计划
- 人才盘点后，对高潜/待提升人员批量生成IDP
- 晋升准备期，差距到发展的系统化拆解
- 管培生轮岗结束后的发展路径规划

## §B 输入示例

**示例1：综合短板**
```
张老师，产研团队leader，当前评分：团队管理2.8/战略思维3.0/组织发展2.5。
12个月内冲刺人力资源总监。
```

**示例2：单项突破**
```
李老师，招聘主管，结构化面试能力2.0。
6个月内把面试能力拉到4.0。目标岗位：招聘经理。
```

**示例3：批量生成**
```
以下3人的能力差距数据已整理。请为每人各生成一份IDP：
- 王二：绩效管理2.5、数据分析2.0→HRBP Director，12个月
- 赵五：项目管理2.8→技术总监，6个月
- 陈七：跨部门沟通3.0、向上管理2.5→部门经理，9个月
```
