# IDP 个人发展计划生成器 - 需求说明书

## 1. 目标
输入能力差距数据（来自岗位胜任力评估或绩效面谈），自动生成结构化个人发展计划（IDP），包含发展目标、行动方案、时间节点和验收标准。

## 2. 核心功能
- **差距到计划转化**：将能力缺口转化为可执行的70-20-10发展动作
- **目标岗位对齐**：支持"我要12个月内成为高级XX"的目标导向模式
- **SMART目标生成**：每条发展动作附带可量化的验收标准
- **里程碑跟踪**：按季度拆解阶段里程碑

## 3. 运行逻辑

### 3.1 输入
- 员工当前岗位与目标岗位
- 能力差距清单（薄弱项+等级）
- 发展周期（3/6/12个月）

### 3.2 输出结构
```
YAML frontmatter（标题+姓名+岗位+周期+日期）
→ 发展总览（差距项数+目标岗位+周期）
→ 发展计划明细表（差距项→发展目标→70-20-10动作→时间节点→验收标准）
→ 里程碑路线图（季度阶段目标）
→ 备注提醒
```

## 4. 70-20-10分配原则
| 岗位层级 | 在岗实践 | 辅导反馈 | 正式学习 |
|---------|---------|---------|---------|
| 基层 | 60% | 20% | 20% |
| 中层 | 70% | 20% | 10% |
| 高层 | 80% | 10% | 10% |
